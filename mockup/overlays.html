New overlay

Private files with their own history, readers and key. They travel encrypted with every push.

A hidden overlay leaves no name, reader, pattern or operation in the shared project. Others see nothing. A visible overlay cannot become hidden later.

This machine becomes the first key manager. Add a second manager soon, so a lost laptop cannot lock the key.

$ overlay createlayr overlay create secrets --readers alice,bob,machine:executor-eu1
$ overlay createlayr overlay create board --readers alice,carol --hidden
$ overlay routelayr overlay route secrets '.env*' 'config/*.key'

Clone shop

Get the project with all lines and states. Data is decrypted on your machine.

layr clone layr+https://cloud.acme.dev/shop

Opens the project as a folder, read only, decrypted on your machine.

layr mount cloud ~/shop

Layr does not serve Git. Mirror states to a Git host when you need one.

Mirror to Git:

layr git push github main
