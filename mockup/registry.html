Images

Every ref, line and change is an image. Same state, same digest.

Images are built on demand from the exact state when a tag is first pulled.

Pull

docker login cloud.acme.dev -u alice --password-stdin
docker pull cloud.acme.dev/shop/app:prod
helm install shop oci://cloud.acme.dev/shop/chart --version 1.4.2

Get a token with layr access token alice. Tokens

Deterministic

Image layers come from the state's files only, so the same state gives the same digest on every machine.

Clone shop

Get the project with all lines and states. Data is decrypted on your machine.

layr clone layr+https://cloud.acme.dev/shop

Opens the project as a folder, read only, decrypted on your machine.

layr mount cloud ~/shop

Layr does not serve Git. Mirror states to a Git host when you need one.

Mirror to Git:

layr git push github main
