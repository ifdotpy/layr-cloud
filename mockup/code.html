shop

The Acme web shop: a Rust API and a TypeScript storefront.

Run it

layr clone layr+https://cloud.acme.dev/shop
cd shop/lines/main
cargo run -p api &
npm --prefix web run dev

Layout

  • src/: the API, checkout and tax rules
  • web/: the storefront
  • migrations/: SQL migrations, applied in order

Secrets live in the overlay secrets. Ask alice for read access.
