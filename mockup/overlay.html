Remove reader

The next push starts a new key epoch. The removed reader cannot open anything saved after that.

● Files this reader already copied stay readable to them. Rotate real secrets (passwords, API keys) as well.
$ overlay readerslayr overlay readers secrets alice machine:executor-eu1

Add reader

Layr seals the overlay key to the reader's key in each store at the next push. No new epoch is needed.

$ overlay readerslayr overlay readers secrets alice bob machine:executor-eu1 person:carol@acme.dev=age1c4r…0p3n

Move files into this overlay

From the next state the files live in the overlay. Earlier states keep them in shared history; Layr does not rewrite history.

$ overlay movelayr overlay move secrets config/sentry.dsn

Clone shop

Get the project with all lines and states. Data is decrypted on your machine.

layr clone layr+https://cloud.acme.dev/shop

Opens the project as a folder, read only, decrypted on your machine.

layr mount cloud ~/shop
