# Layr Desk v1 design (reference)

These pages describe Layr Desk v1, which Layr Cloud replaces. They stay as a reference for the
Desk features that Layr Cloud still needs (person keys, passkeys, a gateway of your own). The
current design is in the Layr repository: `docs/cloud-repo-design.md` and `docs/cloud-rfc.md`.
